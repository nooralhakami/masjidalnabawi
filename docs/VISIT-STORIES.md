## 2. كيف يعمل (للزائر)
- زر نجمة على الخريطة (العمود السفلي مع زر الموقع والطبقات) أو الرابط `map.html?visit=<id>` يفتح القصص.
- شريط علوي بقطعة لكل معلم، ورقم المعلم «n / 9»، وتتقدم الشرائح كل 6 ثوانٍ.
- لمسة الجانب الأول: السابق، وبقية الشاشة: التالي (يعكسها اتجاه اللغة). ضغطة مطوّلة أو زر إيقاف: تتوقف. سحب لأسفل أو Esc: إغلاق. الأسهم: تنقّل. Tab محصور داخل الشاشة.
- «تقليل الحركة» في الجهاز: لا تكبير للصورة ولا حركة للنص ولا تقدّم تلقائي، ويختفي زر الإيقاف.
- كل معلم: شرائح النص (2–3) ثم شريحة الصلاة على النبي ﷺ. أزرار: «اعرضه على الخريطة»، «المسار إليه» (يطلب الموقع عندها فقط)، «المصادر» (تعرض المصدرين وتوقف التقدم).
- الصلاة على النبي ﷺ: سطر ثابت بالعربية في كل شريحة مع عدّاد، وبطاقة كاملة في آخر كل معلم. العدّاد في `localStorage` (`salawat-count`) على الجهاز فقط، ويعمل بالذاكرة إن مُنع التخزين.
- العلامة على الخريطة: شارة بنية بحجم ثابت وهالة ذهبية (تدرّج لوني ثابت، بلا `blur` ولا حركة) عند كل تقريب حتى 14، وتبقى مع أي فلتر ما لم يكن هناك بحث.

## 4. بنية `data/visits.json`
```json
{ "id": 542,
  "slides": [ { "ar": "…", "en": "…" } ],           // 20–260 حرفاً، مصدران على الأقل للموقع
  "sources": [ { "t": "عنوان الصفحة", "u": "https://…" } ],
  "images": [ { "src": "visits/542-1.webp", "focus": "30% 50%",   // focus اختياري: الجزء الباقي عند القص
               "alt": { "ar": "…", "en": "…" }, "by": "…", "license": "…", "url": "…" } ] }
```
- الصورة تُوزَّع على الشرائح بالترتيب (`slide % عدد الصور`)، وشريحة الصلاة هي الأخيرة. صور أكثر من عدد الشرائح لا تظهر.
- لغات النص الأخرى: أضف مفتاح اللغة بجانب `ar` و`en` (مثل `"fr": "…"`). غير الموجود يعرض الإنجليزية، والعربية تبقى عربية.

## 5. كيف أُضيف أو أُعدّل
- **معلم جديد:** يجب أن يكون في `pois.json` بتصنيف `historic` (مطابقة OSM وWikidata كما في `places/PLACES.md`)، ثم يُضاف كائن في `visits.json` بالموضع الذي يناسب أهميته. العلامة المضيئة والقصة تتبعانه تلقائياً. المرشّحون وما ينقصهم: `places/CANDIDATES-2026-10-11.md`.
- **صورة:** حوّلها إلى WebP بعرض 640–1000، ضعها في `public/visits/`، وسجّلها بالحقول كلها (الاختبار يرفض بلا `by` و`license` و`alt`).
- **ترجمة نصوص المعالم:** بعد اعتماد المالك للنصوص العربية، تُضاف اللغات الـ24 كمفاتيح في كل شريحة. نصوص الواجهة (`st_*`) مكتملة بـ26 لغة.
- **ترتيب الأهمية:** ترتيب المصفوفة هو الترتيب؛ قرار المالك.

## 9. المفتوح قبل النشر
1. **حقوق الصور (الأهم):** كل الصور تحمل «مقدَّمة من مالك التطبيق · بانتظار تأكيد المصوّر والإذن» (والمساجد السبعة الأولى: `hana_almadina`). تُستبدل بالمصوّر والترخيص أو تُستبدل الصورة.
2. **الوجوه:** راجع صور الغمامة (طفلان) وجبل الرماة.
3. **صورة بئر رومة الثانية:** تأكيد أنها البئر نفسها.
4. **اسم المسجد في صور أحد والمساجد السبعة الثانية:** وُصفت دون جزم.
5. **مراجعة النصوص:** خصوصاً حديث «الصلاة في مسجد قباء كعمرة» (رواه الترمذي وابن ماجه) وعدد شهداء أحد؛ ويُستحسن مصدر أقوى لشهداء أحد (الحالي: صحيفة المدينة وموسوعة عامة).
6. **ترجمة النصوص** للغات الـ24، ومراجعة متحدثين أصليين.
7. **قياس الأداء** على جوال حقيقي.
8. **معالم ناقصة:** جبل أحد، ذو الحليفة (خارج نطاق الطرق، والمسافة مختلف فيها)، متحف دار المدينة، مجمع الملك فهد (ينقصهما الموقع).
9. **النشر:** لا يتم إلا بموافقة المالك (CLAUDE.md).
