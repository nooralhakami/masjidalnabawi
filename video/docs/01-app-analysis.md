## 1. بنية المشروع

| العنصر | الحقيقة في الكود |
|---|---|
| التقنية | Vite 8 مع TypeScript، **بلا إطار** (لا React ولا Next.js) و Tailwind 4 |
| الصفحات | `index.html`: صفحة الهبوط، تُولَّد مسبقاً بالعربية وقت البناء.<br>`map.html`: تطبيق الخريطة. |
| الخريطة | Leaflet 1.9 مع `leaflet-rotate` (تدوير الخريطة وبوصلة).<br>الطبقة الافتراضية: صور فضائية Esri World Imagery.<br>الطبقة البديلة: خريطة OpenStreetMap فاتحة. |
| البيانات | `data/pois.json` (212 معلماً) و`i18n.json` (6 لغات) و`routing.json` (حلقة الممرات) و`rules.json` |
| تطبيق قابل للتثبيت (PWA) | `vite-plugin-pwa`: الواجهة والخطوط والأيقونات تعمل دون اتصال، **أما بلاطات الخريطة فلا تُخزَّن**. |
| الخطوط | مستضافة ذاتياً عبر `@fontsource`، فلا تعتمد على Google Fonts. |
| الجودة | 96 اختبار وحدة و23 اختبار متصفح، ونتيجة Lighthouse لإمكانية الوصول 100 (حسب `V0-PROMPT.md`). |
| أوقات الروضة | مكتبة `adhan` بطريقة أم القرى، على توقيت المدينة UTC+3. |

## 2. المستخدم المستهدف والمشكلة

**الزائر في الساحات**، وهو غالباً:
- يزور لأول مرة.
- قد لا يقرأ العربية.
- يحمل جوالاً.
- يحتاج جواباً سريعاً لأحد ثلاثة أسئلة:
  1. **«من أي بوابة أدخل أو أخرج؟»**: 70 بوابة خارجية (301–370) على أربع جهات، و42 باباً للمسجد (1–42)، كثير منها بأسماء تاريخية.
  2. **«أين باب النساء ومرافقهن؟»**: 16 باباً داخلياً ضمن القسم النسائي، و12 مجمع دورات للنساء، و3 مجمعات مشتركة، ومصلّيان نسائيان، ومدخل منطقة خلف الروضة للنساء.
  3. **«متى يحين دوري للروضة؟»**: باب 37 مع جدول النساء والرجال الحي.

**الجهة المشغّلة:** باركود جاهز للطباعة عند مداخل الفنادق ومراكز خدمة الزوار، مع زر لتنزيل الباركود صورةً PNG.

## 3. تدفّق المستخدم

```
مسح الباركود أو فتح الرابط
        │
        ▼
صفحة الهبوط (index.html، الوضع الليلي افتراضياً)
  ├─ الشعار، و«جاهزة للاستخدام عبر الجوال»، والعنوان، والوصف
  ├─ «ابدأ استخدام الخريطة ←»  ───────────────────────────┐
  ├─ «طريقة التثبيت» ← بطاقتا أندرويد وآيفون بخطوات مرسومة
  ├─ أرقام: 212 معلماً · 112 بوابة · 13 موقفاً بدورين · 6 لغات
  ├─ لوحة الباركود: الرابط، ونسخ، ومشاركة، وتنزيل PNG
  └─ المزايا الست
                                                          ▼
                                       الخريطة (map.html)
  ├─ لوحة زجاجية: الشعار، والعنوان، و«المدينة المنورة · 199 معلم»، واللغة،
  │   والوضع الليلي/النهاري، والرئيسية، والمشاركة
  ├─ البحث: الاسم، أو رقم البوابة، أو رقم المرفق، وبأي لغة ← حتى 8 نتائج
  │   تحت كل نتيجة شارة لونها لون الجهة
  ├─ شرائح التصنيفات (10) ← بجانب كل شريحة عدد معالمها، وزر لإخفاء العلامات
  ├─ بطاقة الروضة العائمة: «الآن: وقت النساء · يتبدّل بعد 2 س»
  │   مع شريط تقدّم، والضغط عليها يفتح باب 37
  ├─ النقر على علامة أو نتيجة ← بطاقة سفلية تُسحب (نصف أو كاملة):
  │     التصنيف، والاسم، والوصف، و«سبب التسمية»، والجهة، ورقم المعلم،
  │     وأقرب بوابة خارجية + المسافة، وأقرب شارع، وزر مشاركة رابط المكان
  │     └─ «رسم المسار من موقعي» ← مسار مشي + ملاحة حية
  │          (المتبقي بالدقائق والأمتار، والمتابعة، وإعادة الرسم عند الخروج
  │           عن المسار، و«إنهاء المسار»)
  └─ أدوات الخريطة: الطبقات، وموقعي، والتكبير، والتدوير والبوصلة
```

### 5.2 الخطوط

### 5.3 الأشكال والعمق
- **أنصاف الأقطار:** `--radius-sm 12` · `--radius 16` · `--radius-lg 22` · `--radius-xl 28` · لوحة الترويسة 24 · الأيقونة 112/512 (22%).
- **الظلال:**
  - عادية: `0 10px 28px rgb(14 77 58 / .14), 0 2px 6px rgb(30 42 38 / .08)`.
  - صغيرة: `0 4px 12px rgb(14 77 58 / .12)…`.
  - الزر الأساسي: تدرّج من `#17785A` إلى `#0E4D3A`، مع ظل `0 10px 22px rgb(11 74 55 / .35)` ولمعة داخلية بيضاء.
- **الزجاج المصنفر:** `--glass rgb(250 249 245 / .82)` مع `blur(18px) saturate(1.4)`، للترويسة والشرائح وأزرار الخريطة وبطاقة الروضة وشريط الملاحة.

### 5.4 الرموز البصرية
- **الشعار وأيقونة التطبيق:** نجمة ثمانية (مربعان متراكبان بزاوية 45° حول دائرة) بخط ذهبي على مربع أخضر `#0E4D3A`. الملفات: `public/icons/icon.svg` و`icon-512.png`.
- **النقش:** الزخرفة نفسها مكرّرة كخلفية (`.hero-pattern`) بشفافية 16–28%. هذا هو «موتيف» الفيديو الطبيعي.
- **الأيقونات:** مجموعة SVG خطية خاصة (`src/ui/icons.ts`)، منها: `gate` (قوس باب) و`women` و`men` و`mixed` و`prayer` و`dome` و`route` و`locate` و`walk` و`clock` و`globe`. لا رموز تعبيرية في الواجهة.
- **الدبوس المختار:** دائرة بإطار ذهبي عليها رقم البوابة، مع نبض.
- **شعار الهيئة:** `public/haramain-logo.png` بدقة **225×225 فقط**، وهي منخفضة للفيديو (انظر السؤال 3).

### 5.5 لغة الحركة الموجودة
| Token أو العنصر | القيمة |
|---|---|
| `--ease` | `cubic-bezier(0.2, 0.7, 0.2, 1)`: خروج ناعم |
| `--spring` | `cubic-bezier(0.22, 1.15, 0.36, 1)`: نابض بتجاوز خفيف (15%) |
| `--dur` | `200ms` |
| البطاقة السفلية | `transform 280ms var(--spring)` |
| ظهور العلامات | `mk-in 200ms` |
| سقوط الدبوس | `pin-drop 320ms var(--spring)`، ثم نبض `1.8s` |
| رسم المسار | `stroke-dashoffset 900ms var(--ease)`، ثم تدفّق متكرر `route-flow 1.2s linear` |
| نقطة موقعي | `me-pulse 2s` |
| شريط الروضة | `width 600ms var(--ease)` |
| الطيران إلى المكان | `flyTo duration .8s` |
| تقليل الحركة | `prefers-reduced-motion` ← `--dur: 0ms` |

**القاعدة للفيديو:** نستخدم المنحنيين نفسيهما (`ease` للدخول والخروج، و`spring` للبطاقات والدبابيس)، بمدد 200–900ms، وحركة قصيرة المسافة بلا دوران ولا ارتداد قوي.

- بنيت التطبيق (`npm run build`) وشغّلته في Chromium عبر Playwright.

## 7. ملاحظة على الكود (للعلم، ليست ضمن مهمة الفيديو)
في بطاقة الأبواب المسمّاة (مثل 1 و17 و37)، يتكرر **نص الوصف نفسه مرتين**: مرة تحت العنوان، ومرة تحت «سبب التسمية». السبب أن `src/ui/sheet.ts` يستدعي `ds(p)` في الموضعين. ظاهر في لقطتي `G-01` و`G-05`.

في الفيديو سنعرض لقطة البطاقة بحالة «نصف الارتفاع» أو نقصّ الإطار، حتى لا يظهر التكرار. أو نصلحه في التطبيق أولاً إن رغبت.

## 8. ما يصلح «لحظةً بطلة» في الفيديو (من الكود فقط)
1. **من الباركود إلى الخريطة:** لوحة الباركود ثم الخريطة بكل بواباتها.
2. **«بوابات الحرم 112»:** تضيء رقاقات البوابات بألوان الجهات الأربع.
3. **كتابة «17»** ← باب عمر بن الخطاب: «ويقع ضمن القسم النسائي» + أقرب بوابة خارجية 330 على بعد 108 م.
4. **«الخدمات النسائية 33»:** النقاط البنفسجية وحدها على الخريطة.
5. **بطاقة الروضة:** «الآن: وقت النساء · يتبدّل بعد 2 س» مع شريط التقدّم.
6. **رسم المسار:** خط أخضر يتدفّق نحو دبوس ذهبي، مع «13 دقيقة · 980 م».
7. **ست لغات:** الاسم نفسه يتبدّل بين الخطوط والاتجاهات.
