# tests — الاختبارات

> يُقرأ حين تكتب اختباراً أو تشغّله. ما يحميه كل ملف: `docs/PARITY.md`.

## التشغيل
- **الوحدة:** `npm test` (Vitest).
- **e2e:** `npm run test:e2e` (Playwright على نسخة البناء، ويبني بنفسه).
- **Chromium:** المتصفح بهذا الترتيب: `$CHROME` إن مُرّر، ثم متصفح الحاوية (`/opt/pw-browsers/chromium-1194/...`) إن وُجد، ثم متصفح Playwright نفسه (Chromium 1243). ولا تشغّل `playwright install` في الحاوية.
- **الفحص التلقائي (`.github/workflows/checks.yml`):**
  - `checks`: typecheck، و`npm run lint` (Biome)، والوحدة، والبناء.
  - `e2e`: Playwright كاملاً على نسخة البناء، بإعادة محاولة واحدة.

## دروس
- **ما يفعله الـfixture:** يرد بـ404 على ملف بناء غير موجود، كما يفعل Vercel. أما `vite preview` فيرسل الصفحة نفسها، وهذا أخفى خللاً منع القصص من الفتح على الموقع الحي (2026-10-24).
- **WebGL:** يعمل على SwiftShader بالعلَم `--use-angle=swiftshader`. رسائل GL في الطرفية ضجيج، والـfixture يتجاهلها.
- **التوقيت:** لا تنتظر وقتاً ثابتاً ثم تقرأ النتيجة. استعمل `expect.poll` أو تأكيداً بمهلة، لأن الجهاز المثقل أبطأ. هكذا ثُبّت اختبار القصص واختبارا المسار الحي (2026-10-24).
- **معاينة التطوير:** إن بدا CSS قديماً فأعد تشغيل المعاينة. وخطأ "Outdated Optimize Dep" يعني امسح `node_modules/.vite`.
