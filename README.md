# دليل زوار المسجد النبوي

موقع ثابت قابل للتثبيت كتطبيق (PWA) يرشد زوار المسجد النبوي في المدينة المنورة: البوابات ودورات المياه والمواقف والخدمات، مع بحث ذكي وفلاتر ومسارات مشي وست لغات (العربية، English، Türkçe، اردو، Bahasa Indonesia، O‘zbekcha).

- `index.html` صفحة الهبوط: تعريف بالخريطة، باركود QR، المزايا، طريقة التثبيت.
- `map.html` تطبيق الخريطة التفاعلية.

**للمطوّرين (Claude ومطوّري الهيئة) — Developers start here:**
1. [`SPEC.md`](SPEC.md) — ما يجب أن يفعله التطبيق، وشروط القبول، وقرارات المالك، وقائمة التحذيرات (ملزم).
2. [`ARCHITECTURE.md`](ARCHITECTURE.md) — أجزاء الكود وحدودها وتدفقها ونقاط الدمج (English + ملخص عربي).
3. [`CLAUDE.md`](CLAUDE.md) / [`AGENTS.md`](AGENTS.md) — قواعد العمل، وتعريف «تم»، والدروس المستفادة.
4. [`docs/PERF.md`](docs/PERF.md) و`npm run perf` — ميزانية السلاسة. [`docs/places/PLACES.md`](docs/places/PLACES.md) و[`docs/routes/NETWORK.md`](docs/routes/NETWORK.md) — مصادر البيانات وبناؤها.

البرومبتات القديمة لـ v0 والمواصفات الأولى (`PROMPT.md`) أصبحت أرشيفاً في `docs/history/`، والتطبيق القديم للمقارنة في `reference/current-app.html`.

## التشغيل المحلي
يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm run dev
```

افتح `http://localhost:5173/` لصفحة الهبوط، و`http://localhost:5173/map.html` للخريطة.

## الأوامر
| الأمر | الوظيفة |
|---|---|
| `npm run dev` | خادم التطوير مع إعادة التحميل الفوري |
| `npm test` | اختبارات الوحدة (Vitest): البيانات، الفلاتر، البحث، المرافق، الروضة، المسارات، الترجمات |
| `npm run test:e2e` | اختبارات المتصفح (Playwright، مقاس 390×844) على نسخة البناء |
| `npm run build` | فحص الأنواع ثم بناء مجلد `dist/` |
| `npm run preview` | معاينة نسخة البناء (يعمل فيها Service Worker) |

أول مرة لاختبارات المتصفح: `npx playwright install chromium`.

## البناء والرفع
```bash
npm run build
```

ينتج `dist/` بروابط نسبية، فيعمل على أي استضافة ثابتة وفي أي مسار فرعي:
- **Vercel:** ملف `vercel.json` يحدد الإعداد (Vite، البناء `npm run build`، النشر من `dist`).
- **Netlify:** أمر البناء `npm run build` ومجلد النشر `dist`.
- **GitHub Pages أو أي خادم:** ارفع محتوى `dist/` كما هو.

يُفضَّل استضافة تدعم HTTPS (مطلوب لتثبيت التطبيق وتحديد الموقع) وHTTP/2 مع الضغط.

## تغيير الباركود

الباركود يُولّد تلقائياً من `QR_URL` ويشير حالياً إلى `https://masjidalnabawi.vercel.app/` (الصفحة الرئيسية)، لذلك يتطابق الرابط المعروض وزرا النسخ والمشاركة والتنزيل مع الباركود دائماً.

في `src/config/site.config.ts`:
- `QR_URL`: اتركه فارغاً ليشير الباركود تلقائياً إلى `map.html` على نفس الاستضافة، أو ضع رابطاً كاملاً.
- `QR_IMAGE`: مسار صورة باركود جاهزة (ضعها في `public/` واكتب مثلاً `./my-qr.png`) لتحل محل المولَّد.
- `ORG_NAME`: اسم الجهة في التذييل. `DEFAULT_LANG`: لغة البداية.

زر «تنزيل الباركود PNG» في صفحة الهبوط ينتج صورة 1024 بكسل بالأبيض والأسود جاهزة للطباعة.

## روابط الأماكن
زر المشاركة في بطاقة أي مكان ينشئ رابطاً مثل `map.html?poi=215` يفتح المكان نفسه مباشرة. يمكن استخدام هذه الروابط في اللافتات أو الرسائل.

## تعديل حالة المرافق
- **للتجربة والعرض:** افتح `map.html?admin=1` لتظهر لوحة «محاكاة المشرف»: اختر مرفقاً ثم «تغيير الحالة» (مفتوح ⇄ صيانة) أو «أعمال المصعد» (تُطبَّق على المرفق ومقابله معاً). التغيير في هذه الجلسة فقط.
- **الحالة الافتراضية:** الحقل `status` في `data/pois.json` (`open` أو `maintenance` أو `works`، مع `worksBy` للمرفق المقابل). القوائم المرجعية (المرافق النسائية، المصاعد قيد الإنشاء، أزواج الأعمال) في `data/rules.json`.

## ضبط موقع معلم
لا تُعدَّل الإحداثيات في `pois.json`. أضف إزاحة بالمتر في `data/overrides.json`:

```json
{ "332": { "north": -7, "east": 7 } }
```

القيم السالبة جنوباً/غرباً، وتُطبَّق وقت التحميل.

## إضافة لغة
1. أضف كائن اللغة في `data/i18n.json` بنفس مفاتيح `en` (الاسم `n`، الرمز `short`، الاتجاه `dir`، الجهات، الشوارع، `ui`، قوالب الأسماء والأوصاف).
2. أضف الرمز إلى `LangCode` في `src/data/types.ts` و`LANGS` في `src/i18n/index.ts`.
3. أضف ترجمات المفاتيح الإضافية في `src/i18n/strings.ts` و`src/i18n/landing-strings.ts`.
4. شغّل `npm test`: يفشل اختبار الترجمات إن نقص أي مفتاح أو اختلفت المتغيرات `{…}`.

## الموقع والملاحة الحية
- `src/location/LocationService.ts`: خدمة موقع واحدة يشترك فيها زر «موقعي الآن» والملاحة. تُظهر موقعاً تقريبياً فوراً ثم تحسّنه بقراءات عالية الدقة، وتتابع الحركة باستمرار، وتتوقف حين تُخفى الصفحة لتوفير البطارية.
- `src/location/filter.ts`: مرشّح Kalman بنموذج السرعة الثابتة. يزن كل قراءة بدقتها بدل رميها، ويتجاهل القفزات الشاذة المنفردة، ويحسب اتجاه المشي.
- `src/location/progress.ts`: موقع الزائر على المسار للأمام وللخلف، والمسافة المتبقية، واكتشاف الابتعاد عن الوجهة.
- السهم يتبع اتجاه المشي الفعلي، وعند الوقوف يتبع بوصلة الجوال إن أذن بها الزائر.
- لأفضل دقة على آيفون: الإعدادات › الخصوصية › خدمات الموقع › Safari › «الموقع الدقيق».

## ملاحظات تقنية
- **التطبيق القابل للتثبيت:** `vite-plugin-pwa` يولّد manifest عربياً (RTL، يبدأ من `map.html`) وService Worker يخزّن واجهة الصفحتين والمكتبات والخطوط والأيقونات، فتعمل الواجهة دون اتصال. **لا تُخزَّن بلاطات الخرائط** عمداً.
- **الخطوط** مستضافة ذاتياً من npm (`@fontsource`): IBM Plex Sans Arabic للنصوص، Noto Kufi Arabic للعناوين، Noto Naskh Arabic للأردية.
- **الخريطة الفاتحة:** رابط CARTO في `rules.json` صار يتطلب مفتاح API، فتُستخدم بلاطات OpenStreetMap افتراضياً (`LIGHT_TILES` في `site.config.ts`). للزيارات الكثيفة راجع [سياسة OSM](https://operations.osmfoundation.org/policies/tiles/) أو استخدم مزوداً بمفتاح.
- **جدول الروضة:** الفجر والعشاء محسوبان بمكتبة `adhan` (طريقة أم القرى، توقيت المدينة UTC+3).
- **الأداء:** صفحة الهبوط تُولَّد مسبقاً بالعربية وقت البناء، والأنماط مضمّنة في HTML.
- **الأرقام** لاتينية في كل اللغات.
- الدليل إرشادي ولا يستخدم شعارات أي جهة رسمية.
